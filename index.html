CAPABILITIES

Built around the Threads API.

Fayatno uses authorized Threads API capabilities to provide functionality for content and interaction management.

01

Threads Access

Connect an authorized Threads account with Fayatno and access the information required by the application.

02

Content Publishing

Create and publish Threads content through authorized API functionality.

03

Reply Management

Read and manage replies associated with content where the authorized API permissions allow it.

THREADS API

Requested permissions

Fayatno requests only the Threads permissions required for its intended functionality.

threads_basic

Access basic information associated with the authorized Threads account.

threads_content_publish

Allow Fayatno to publish Threads content on behalf of an authorized user.

threads_read_replies

Allow Fayatno to read replies required by the application's reply-management features.

threads_manage_replies

Allow Fayatno to perform permitted reply management actions on behalf of an authorized user.

ABOUT FAYATNO

Users remain in control of their connected account and can revoke access through the available account and platform controls.
